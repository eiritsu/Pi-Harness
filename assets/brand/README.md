## pi-logo-on-dark.svg

- 来源：用户提供（2026-09-19）
- 用途：
  - **应用图标**（M5）：以此为源，栅格化生成 `icon.png`（≥1024px）→ `icon.icns`（macOS）
  - **应用内 logo**（M2）：空态页居中 logo、关于页；深色背景使用，直接内联或作为 renderer 静态资产
- 规格：viewBox 0 0 800 800，三个 path：
  - `#F09082`（橙）
  - `#4D9ABF`（蓝）
  - `#F1BE58`（黄）
- 深色底 `#0d0d0d`（UI tokens `--bg`）上直接使用，无需外加描边/底板
